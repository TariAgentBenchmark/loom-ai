# 后台按功能手动切换线路

## 范围与入口

用户已确认：**只有后台管理员可以切换，只有手动切换**。
入口：后台 → 服务配置 → 功能线路配置（沿用已有 `/admin/services` 和 `/v1/admin/ai-model-routes`）。

不新增前台线路选择，不新增自动切备用，不新增供应商或修改任何真实密钥。
只有服务器已经配置凭据的线路可被选用。配置状态仅说明有凭据，**不表示已经完成供应商连通性/付费生图验证**。

## 可配置功能

共13个配置项，12个现有单线路说明项。

- 保留：综合模型Gemini分支、综合T2 Gemini分支的现有配置及模型范围。
- 新增用嘴改图模型1的2K、4K独立配置；不改变原new/original/pro_4k等请求值、提示词、参考图顺序和价格。
- 新增模型pro 2K、综合模型原普通香蕉（现Seedream）分支：默认Seedream，可手动选已接入Gemini 2K线路。
- 布纹去噪4K、平面转3D 2K、毛线效果2K、四方连续转换、旧通用Gemini分支。
- 矢量化：原配置 / ZFY / A8 / WebAPI。明确选择后三者时只执行选中线路，不自动降级；不能悄悄把EPS/SVG改为其他格式。
- 普通高清：保持原前台引擎 / RunningHub VR2 / 美图超清V2。只替换执行线路，不改任务原engine及其计费；4K超清工作流不受影响。

Gemini线路复用Apyi、Tuzi、Haoee、Kr API既有客户端。Tuzi/Haoee的双参考图按其Gemini协议构建多个inline_data，不丢弃第二张图。
模型1的4K与去噪4K配置只允许4K模型，不能选Seedream或2K模型。
四方连续默认保留原Gemini2.5调用，不强制换新模型。

通用四图、定位、牛仔、烫画、综合GPT/RunningHub分支、接循环、扩图、去水印、相似图、刺绣效果、4K超清目前无已接入的同能力第二线路，显示为“单线路”且不能修改。
已有GPT VIP→标准、矢量化“原配置”的兜底不在本次重写；选中明确矢量线路后不会再使用原降级链。

## 生效与安全

- 保存服务器SystemSetting，不覆盖.env，不通过前端传递API密钥。
- 新任务在创建时冻结线路；批量父任务和所有子任务使用同一快照。
- 切换不迁移排队/处理中任务。任务恢复时优先使用原快照；升级前没有新配置项的任务补旧默认值，而不是采用管理员的新选择。
- 原有Seedream任务号恢复、防重复提交及综合部分结果交付逻辑保留；综合分支手动改用Gemini时，也按不可查询的付费调用记录开始标记与结果缓存。
- 失败不会新选另一供应商；原客户端同一线路的HTTP重试行为不在本次重写。
- 默认线路不变，不因为部署就自动把旧用嘴改图从API易切走。管理员需要在后台明确选择并保存。
- 积分仍按原功能、模型模式及前台引擎计算，不按所选供应商改变价格。

## 测试范围

自动化覆盖管理员GET/PUT与普通用户403、未配置凭据拦截、单线路只读、4K禁止2K线路、供应商切换后的参数与双图顺序、失败不跨供应商、创建快照与恢复冻结、批量父子快照一致、原价格不变、旧Seedream卡任务回归。

上线检查应验证后台实际返回字段和页面保存行为、原功能默认值与现有任务保持不变。
没有额外授权时，不自动遍历所有供应商提交付费生图测试。
